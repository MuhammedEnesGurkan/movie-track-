# WatchList

Dizi/film takip + "hangi platformda?" MVP'si. Next.js 14 App Router, TS, Tailwind, Supabase, TMDB (region=TR).

## Kurulum

1. `npm install`
2. `.env.example` dosyasını `.env.local` olarak kopyala, Supabase ve TMDB anahtarlarını doldur.
3. `supabase/migrations/001_init.sql` dosyasını Supabase projende çalıştır.
4. `npm run dev`

Vercel'e deploy ederken aynı env değişkenlerini proje ayarlarına ekle.
